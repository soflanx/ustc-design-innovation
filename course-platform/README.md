# 设计创新课程平台

本地可运行的教学原型：Next.js App Router、TypeScript、Prisma 与 PostgreSQL。课程成员、分组、资料、作业提交与文字反馈读写真实数据库。公开首页提供课程介绍、新闻、故事和课程学期入口。新闻用于课程通知、活动报道与项目进展；故事用于人物经历、项目过程与设计思考，不限定学生或小组。图片来源记于 `public/images/portal/sources.json`。

## 运行

需要 Node.js 22.12+ 和 PostgreSQL 16+ 命令行工具（`initdb`、`pg_ctl`、`psql`、`createdb` 在 PATH 中）。在此目录执行：

```sh
npm ci
npm run db:local
npm run db:generate
npm run db:migrate
npm run db:seed
npm run dev
```

访问 <http://127.0.0.1:4174>。师生入口提供虚构的教师、助教、两位学生与管理员账号。演示入口同时要求 `NODE_ENV=development`、`DEMO_AUTH_ENABLED=true` 及本机 `APP_URL`；生产模式不会开放演示登录。

`db:local` 创建项目独立的 PostgreSQL 实例，监听 `127.0.0.1:55433`。数据位于 `.local/postgres/`；自动生成的密码与 `.env` 已排除版本控制。已有 `.env` 不会被覆盖。执行 `npm run db:stop` 可停止数据库，保留数据。开发服务器在运行终端按 Ctrl+C 停止。

## 课次与 Markdown

进入课程后，在「课次」目录点「新建课次」。填写标题即可建立草稿，也可以写正文并引用已发布的作业或资料。每个课次有独立地址、草稿和发布时间。课次的「课程内容」和「课堂记录」共用一个标题，本期有效教师与助教可在两者间切换，学生只能阅读已发布的课程内容。首页和课次都默认连续写 Markdown，需要图片、作业或资料时可在光标处插入。拖动、折叠与合集保留在「调整布局」。具体操作见[课程页面使用说明](docs/course-page-editor.md)。

## 当前可操作的流程

从课程、作业、资料或小组链接登录后，会返回原页面并保留适用的筛选条件，目标页面仍会检查权限。没有来源时，只有一门进行中课程的成员会直接进入课程首页；「我的课程」可切换课程、查看筹备期和往期记录，管理员使用「全部课程」。不同课程的身份独立生效。

同一期课程使用一个首页。首页只有一个「编辑课程首页」入口，教学团队自行决定通知、回顾、课前准备和各条引用的顺序与篇幅。旧回顾和准备分别在已发布版和草稿中展开为普通正文，编辑后随正文保存。学生读首页已发布正文，可通过「查看作业与提交情况」核对当前状态，也可从「最近成果」打开对应的正式提交版本。

教学团队点击「编辑课程首页」或「编辑课次」后在单列画布中编辑，顶部「插入」、块左侧加号和 `/` 提供新建作业／资料、关联已有记录及基础块。标题与每条记录分别是独立块；桌面鼠标从正文旁留白或行尾空白直接拖框，松手后拖动已选正文或六点整体移动，支持边缘自动滚动和 Escape 取消。六点还提供复制、转换、删除和连续范围选择，拖动带数量、内容预览与蓝色落点。`•••` 可更换关联和切换链接／卡片；手选合集可拆成独立引用。触屏继续使用点按与菜单，正常文字涂选不变，键盘可用 Alt+Shift+B。

页面「保存草稿」和「发布课程首页／课次」分开：草稿由本期教学团队共享，学生读取接口只返回已发布内容；Cmd/Ctrl+S 保存草稿。学生预览对当前编辑应用发布可见性规则，发布核对时按最新状态和本次选择展示，隐藏未选草稿，不携带教师统计或个人进度，小组用实际组籍归属提示占位。课次内新建作业和资料默认先存草稿，新建成功把引用加入当前未保存编辑；配套文件可随作业草稿一次保存。发布正文时明确勾选的草稿及配套资料与页面统一发布，未选仍隐藏。独立「布置作业」只保存或发布作业，不打开或修改课程首页正文。放弃页面编辑不撤销已保存记录；新建请求通过稳定标识避免重试重复创建。页面与各条记录使用独立修订号检查冲突。实现与范围见 [可编排课程页面](docs/course-page-editor.md) 和 [课程内容生命周期](docs/course-content-lifecycle.md)。

「课程首页」「课次」「作业」在主导航。本期教师与助教可直接进入「学生」和「小组」，学生可进入「我的小组」。资料、教学团队和课程管理入口按身份显示。学生从作业目录核对按当前个人或小组归属计算的提交状态，并打开相应作业查看更正期限。所有内容由服务端按当前读者权限读取，归档后保留回看。

课程内所有页面共用相同导航与简短定位，例如「思维 · 2026秋」。该定位只显示当前位置；品牌返回教学入口，「我的课程」返回课程选择，「网站首页」返回公开门户。侧栏以「课程首页」明确当前教学页面的位置。未交任务定位实际提交区，教师编辑定位该作业并展开表单；课程资料标题直接打开附件或外链，教师可从编辑表单返回原搜索结果。

1. 教师从「我的课程 → 发布课程」进入，默认选中本学期，在思维、实践两门课中直接发布。思维春秋均开，实践秋季为Ⅰ、春季为Ⅱ；课程名称、日期与负责人关系自动准备。发布直接进入本期课程编辑页，不再手填课程名称与学期日期。既有同期开课直接进入，归档不会因重试重新开放，也不复制旧学生、小组与内容。
2. 在「课程管理」添加课程成员和分配助教。教师在「小组」设置每组人数上限和北京时间截止，开放学生自助组队。学生从课程首页进入组队，可以在本班招募、凭同学发来的链接加入，或确认加入仍有余位的公开招募组。确认后即成为正式成员。需人工安排或调组时，教师仍可从「课程管理」处理，组籍变动保留历史。
3. 切换为学生后，进入自己的小组，展开「编辑项目标题与工作记录」。保存核对记录修订号，冲突时保留本次编辑并展示服务器最新内容，核对后才能再次保存。每次保存保留不可改写的历史；载入旧版只改变编辑区，保存才形成新版本。教师与助教可查看本学期各组；仅本组成员及管理员可编辑主页。
4. 教师或管理员在课程主页新建资料，列表和详情维护已有记录。资料说明与外部链接独立保存；草稿及下架资料仅管理者可读，发布后本期成员可读。资料发布不发布页面文字，外部文档权限由原平台管理。
5. 教师或管理员在课程主页新建个人或小组作业，设置北京时间截止时间，从草稿发布。已发布作业可结束或填写原因后取消，不可退回草稿；取消表示免交，可明确恢复发布，截止时间仍有效。已有提交后不能改提交方式。
6. 学生交回一份当前正式成果，可以附多个文件和文字说明，至少提供一个附件或一段说明。个人成果归本人，小组成果归服务端核对的当前组。更正可保留或移除原附件并加入新文件。每次正式交付或更正都封存材料、当时的参与者和要求修订，学生优先看到当前成果，按需展开更正历史和旧反馈。提交前若要求、归属或当前成果有变化，保留草稿并请学生重新核对。相同成功请求重试返回原回执。
7. 截止前可以更正已交成果。作业已截止且仍发布时，教学团队可为指定的一份已交成果开放至明确期限，也可撤销开放。开放不授权首次补交，也不改变其他学生的截止时间。作业结束、取消或课程归档时停止提交与更正。
8. 本期有效教师与助教从「课次」进入本次课，打开「课堂记录」后点「记一笔」。填写正文即可保存整堂课的记录。按需关联一位学生或一个小组，未分组学生也可以选。保存后在同一课次回看，学生页和小组页也可直接记一笔。
9. 游客可阅读公开新闻、成果、课程目录及已开放/归档课程简介；教学资料、作业、教学团队、小组内容和筹备中课程受服务端鉴权保护。
10. 本期教师、助教或管理员可编排、保存共享草稿和发布课程首页；助教不能因此管理正式作业和资料。所有引用限定同期开课，学生只看到其原本有权读取的记录；助教保存时保留其无权读取的资料关联。归档后页面只读。课程筹备中仍允许有效学生阅读已发布页面和记录，只禁止提交，不等于私有准备区。图片仍使用已有地址。

「课堂记录」保存正文、作者和登记时间。从课次打开时自动带入本课。可选现场观察、课堂发言、收到请假、已确认请假或教学判断，按需补充发生日期、情境或来源。个人记录还可关联当时的小组。新写入的发生日期只记录北京时间的日历日期，最晚可填当天。两类请假均须关联一位学生，「已确认请假」还须填写已有决定的来源。记录缺失只表示暂无记录。未保存的记录草稿按账号、开课和记录情境留在当前标签页，确认保存后清除。

课堂记录仅本期有效教师和助教可读，课程归档后只读。归档前，原作者可更正本人记录。原作者和本期有效教师可以填写原因后撤回记录。教师撤回他人的误记时保留原文和署名，助教只能撤回本人记录。全站管理员身份本身不授予上述权限。原文和修订均保留，本课的「查看已撤回」可打开已撤回条目。

教学团队可从「学生」按姓名找到学生，包括未分组和暂无记录的人，也可从小组页点组员姓名。学生标题旁的当前组名直达小组，有旧组经历时也可回看。学生和小组页连续呈现已有的课堂备注、作品和原版评语，小组页还保留成员和工作正文。从本课记录进入学生或小组后，可返回本课。旧观察保留原文和日期，未知的课次、类型和小组情境留空。

已发送的个人及小组留言沿用原读者规则。旧未发送留言草稿可在原浏览器标签查看、复制和清除。独立发送留言的界面已收起，新的作业评语写在对应成果版本。学生从「本学期记录」回看个人提交、参与过的组成果和当时收到的旧留言，在「我的小组」查看当前组员、招募和作业入口。整站结构、实施批次和验收协议见[课程网站整体设计与分批实施](docs/course-workflow-redesign.md)。

打开作业默认先读要求。教师与助教可点「查看提交情况」，按当前正式成果、待评阅、已评阅、未提交或更正历史查看。助教默认看负责范围，可切换全班，个人作业也可单看未分组学生。打开一份提交可在该版本的独立页面阅读材料、写评语，再返回原统计范围。评语与评阅状态各自保存，教师与助教可完成或重新打开该版评阅。`PENDING`、`COMPLETED`、`LEGACY_UNKNOWN` 表示版本评阅进度，状态变化保留历史。取消作业后保留已有成果和评语，停止催交。学生可查看自己参与的历史成果，也可读当前组共享的既有成果和组级留言。加入新组不改变历史参与者，个人专属留言仍仅对原读者可见，离组学生保留原有历史阅读范围。

每次作业保存产生不可改写的要求修订，包含要求、方式、截止时间、状态和取消原因，历史满分字段仅为数据兼容保留，界面不提供满分输入或默认分数显示。详情按需展开「修改记录」及每次提交的「提交时的作业要求」。旧提交没有快照时明确显示未知，不拿当前要求或后来建立的基线回填。移除主页引用不会删除正式记录，当前没有作业、资料、提交或反馈的物理删除入口。

提交说明最多 12000 字。一次正式成果最多包含 20 个附件，保留与新增附件合计最多 10 MiB。浏览器草稿按账号、开课和作业保存说明、选件记录和核对信息，文件字节不会随草稿保存，刷新后须重新选择新增文件。提交失败时当前页保留选件和文字，确认成功后清除本地草稿。调组或要求变更时须核对新的归属或要求；已成功但响应丢失的请求，可在截止或调组后核对原结果。已交附件由服务端按该成果的读取权限提供，旧链接仍需重新授权。课程资料支持在已授权标题与正文中搜索。

发布页面前会重新读取有权查看的记录状态，按记录去重汇总草稿、已发布、已结束、已取消与已撤回状态。只有包含学生不可见或受保护关联时才增加行内核对；再次确认也会重新读取状态，保留编辑内容、撤销记录与未保存正文。摘要不输出隐藏记录标题、正文或推测其数量。修改已发布正式记录前，表单说明保存会立即生效。

角色按开课范围生效。课程负责人另存为长期关系，管理员另存为全站权限；新增某一期教师不等于新增长期负责人。助教负责小组的分工不限制其查看本期其他小组的权限。

## 数据与验证

- `prisma/schema.prisma`：长期课程、学期、开课、课程成员、小组及完整教学记录模型。
- `prisma/migrations/`：可复现的初始迁移及后续历史保护迁移；包含复合外键、条件唯一索引与封存规则。请使用迁移，不要用 `prisma db push` 替代。
- `docs/data-model.md`：实体、约束及应用层仍需实现的边界。
- `src/lib/management.ts`：管理操作的权限检查与事务。
- `src/lib/teaching.ts`：作业、正式成果、附件权限、更正期限及历史读取。
- `src/lib/teaching-observations.ts` 保存课堂记录和修订的授权与事务，保留旧外发留言的兼容服务。
- `src/lib/resource-service.ts`：资料的开课范围授权、发布状态和链接验证。
- `tests/`：权限及数据库完整性集成测试。

```sh
npm test
npm run typecheck
npm run build
```

`npm test` 仅连接本机 PostgreSQL，每次创建随机命名的隔离数据库，应用全部迁移，完成后删除该临时库；不会向开发库写入测试样例。测试文件串行执行，避免共享临时库的无关 fixtures 触发序列化冲突；文件内明确的并发测试仍同时执行写入。数据库用户需要建库权限。种子数据为虚构内容，重跑仅补充缺失记录，不覆盖已有编辑。
