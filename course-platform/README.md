# 设计创新课程平台

本地可运行的教学原型：Next.js App Router、TypeScript、Prisma 与 PostgreSQL。课程成员、分组、资料、作业提交与文字反馈读写真实数据库。公开首页提供交流动态、学生故事、故事总览和课程学期入口，图片来源记于 `public/images/portal/sources.json`。

## 运行

需要 Node.js 22.12+ 和 PostgreSQL 16+ 命令行工具（`initdb`、`pg_ctl`、`psql`、`createdb` 在 PATH 中）。在此目录执行：

```sh
npm ci
npm run db:local
npm run db:generate
npm run db:migrate
npm run db:seed
npm run dev
```

访问 <http://127.0.0.1:4174>。师生入口提供虚构的教师、助教、两位学生与管理员账号。演示入口同时要求 `NODE_ENV=development`、`DEMO_AUTH_ENABLED=true` 及本机 `APP_URL`；生产模式不会开放演示登录。

`db:local` 创建项目独立的 PostgreSQL 实例，监听 `127.0.0.1:55433`。数据位于 `.local/postgres/`；自动生成的密码与 `.env` 已排除版本控制。已有 `.env` 不会被覆盖。执行 `npm run db:stop` 可停止数据库，保留数据。开发服务器在运行终端按 Ctrl+C 停止。

## 当前可操作的流程

从课程、作业、资料或小组链接登录后，会返回原页面并保留适用的筛选条件，目标页面仍会检查权限。没有来源时，只有一门进行中课程的成员会直接进入课程首页；「全部课程」可切换课程、查看筹备期和往期记录。不同课程的身份独立生效。

课程进入页先显示教师或助教自由维护的「当前教学内容」：标题、说明，以及按需关联的作业和资料。没有固定阶段、周次或自动推定的进度；未填写时明确显示待发布，不把全部作业冒充当前安排。小组、教学团队和完整作业目录由次级导航进入。关联作业内，学生优先看到开放未交任务，其后为已有反馈；教师优先看到最新版本待反馈的任务。助教的摘要和主操作按当前负责小组计算，可切换全班。尚未接入反馈已读状态，因此只显示“已有反馈”。

课程内所有页面共用相同导航与简短定位，例如「思维 · 2026秋」。该定位只显示当前位置；「全部课程」回到课程选择，每期开课仅一个入口。未交任务定位实际提交区，教师编辑定位该作业并展开表单；资料详情可返回原搜索结果。

1. 教师在「我的课程」创建新学期，长期课程负责人自动加入新一期教学团队。新一期默认筹备中，不复制旧学生与分组。
2. 在「课程管理」添加现有账号作为本学期教师、助教或学生，创建小组、分配或调整组员，分配或结束助教分工。学生同期开课只有一个当前小组；变动保留历史。
3. 切换为学生后，进入自己的小组，展开「编辑项目标题与工作记录」，保存后刷新页面验证持久化。教师与助教可查看本学期各组；仅本组成员及管理员可编辑主页。
4. 教师或管理员在「课程资料」保存说明与外部链接。草稿及下架资料仅管理者可读，发布后本期成员可读；外部文档权限由原平台管理。
5. 教师或管理员在「作业与反馈」创建个人或小组作业，设置北京时间截止时间，从草稿发布。发布后的作业可结束并保留记录，不可退回草稿；已有提交后不能改提交方式。
6. 学生提交纯文字正文。个人作业归本人，小组作业由服务端推导当前组及有效组员。每次提交保留独立封存版本和参与者快照，重复请求不会产生重复版本。达到截止时间即停止接受新提交。
7. 教师与助教可查看本期全部提交并添加文字反馈。学生仅能查看自己参与的历史版本与对应反馈；调组后不获得新组的旧提交，也不丢失自己的原组历史。管理员没有本期教师/助教身份时只能查看，不能署名反馈。
8. 课程归档后，成员、分组、主页、资料、作业、提交与反馈均只读，教师或管理员可重新开放课程。
9. 游客可阅读公开新闻、成果、课程目录及已开放/归档课程简介；教学资料、作业、教学团队、小组内容和筹备中课程受服务端鉴权保护。
10. 本期教师、助教或管理员可直接编辑「当前教学内容」，不需要先配置教学阶段。可只写说明，也可关联同期开课的作业和资料；学生只看到其原本有权读取的关联内容。归档后保留只读。

作业详情为教师提供「最新提交」「待反馈」「未提交」「全部版本」筛选。概览按当前有效学生或小组的最新版本统计，旧版反馈不会使新版自动变为已反馈；退出成员和空组仍保留历史，不计入当前应交数量。助教默认查看负责小组，可切换全班。学生首页显示当前归属且本人可查看的提交状态，历史小组记录仍可在详情阅读。

学生作业正文按账号、开课和作业保存浏览器草稿，刷新可恢复，提交失败保留，确认成功才清除；本地草稿不跨设备同步，不等于正式提交。截止、作业结束或课程归档后，仍有课程读取权限的学生可只读查看、复制草稿，不改变其正文或原分组信息。调组前打开的旧页面会拒绝误交；恢复旧组草稿时须核对并确认新的提交小组。课程资料支持在已授权的标题与正文中搜索。

角色按开课范围生效。课程负责人另存为长期关系，管理员另存为全站权限；新增某一期教师不等于新增长期负责人。助教负责小组的分工不限制其查看本期其他小组的权限。

## 数据与验证

- `prisma/schema.prisma`：长期课程、学期、开课、课程成员、小组及完整教学记录模型。
- `prisma/migrations/`：可复现的初始迁移及后续历史保护迁移；包含复合外键、条件唯一索引与封存规则。请使用迁移，不要用 `prisma db push` 替代。
- `docs/data-model.md`：实体、约束及应用层仍需实现的边界。
- `src/lib/management.ts`：管理操作的权限检查与事务。
- `src/lib/teaching.ts`：作业、提交快照、历史读取与反馈事务。
- `src/lib/resource-service.ts`：资料的开课范围授权、发布状态和链接验证。
- `tests/`：权限及数据库完整性集成测试。

```sh
npm test
npm run typecheck
npm run build
```

`npm test` 仅连接本机 PostgreSQL，每次创建随机命名的隔离数据库，应用全部迁移，完成后删除该临时库；不会向开发库写入测试样例。数据库用户需要建库权限。种子数据为虚构内容，重跑仅补充缺失记录，不覆盖已有编辑。

本机开发服务器运行时可执行 `npm run test:http`，检查会话、来源校验、退出失效、角色首页、资料与作业读取及跨期开课隔离。此检查使用演示账号、初始 A/B 组关系和 seed 中的示例资料/作业，仅创建并清理自己的临时登录会话；若手动调整演示数据，需要相应更新检查预期。

## 后续阶段

已实现文字资料、个人/小组文字作业、提交版本与组员快照、文字反馈。文件上传与私有下载、成绩发布和修改历史、正式认证、用户导入、课表、教学笔记、新闻成果发布后台与部署仍属于后续工作。当前使用本地虚构演示账号，尚未接入学校认证；作业正文目前上限 12000 字，不支持附件。

成绩修改须由后续服务在同一事务写当前成绩及历史；学生仅应看到已发布成绩。数据库约束不替代提交归属、文件读取及学生可见性的服务端验证。正式启用前应完成这些流程及相应端到端验证。
