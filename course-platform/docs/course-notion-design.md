# 课程页面的类 Notion 结构设计说明

更新日期：2026 年 11 月 7 日

适用范围：课程首页、课程下面的一层子页面，以及两者共用的编辑器。

当前的原则是「页负责导航，Markdown 负责文字，对象负责独立内容」。首页说明本周做什么；工作坊指南、作品选读等可以各自拥有稳定网址和草稿。子页直接属于本学期开课，改名不改网址。普通 Markdown 链接可以指向另一页，没有递归页面树或整页嵌入。

写作时正文连续输入：空行分段，标题、列表、强调和引用直接使用 Markdown。图片、作业与资料可以在光标处独立插入，之后继续写。作业引用指向原作业，提交、点评和成绩仍遵守原来的权限。确实需要调整复杂结构时才进入「调整布局」；已有折叠、合集和嵌套内容可以原样保留。下面的块级交互说明适用于该布局模式。

首页和子页面共用同一正文结构、编辑工具与发布流程。首页的子页目录和课程待办在正文之外；子页只增加返回课程首页的入口，不再嵌套下一层。学生从课程首页的「课程子页面」进入已发布页；教师和助教可以新建、保存草稿、预览、发布及撤回。更新草稿不影响学生当前可读版本。归档课程只读。

## 1 整体由三层组成

| 层次 | 解决的问题 | 当前内容 |
| --- | --- | --- |
| 课程导航 | 到哪里找内容、办理事情 | 课程首页可编写教学安排或布置作业。「作业与反馈」可布置作业和查看提交，「课程资料」可添加和查找资料。另有小组、教学团队与课程管理 |
| 可编排页面 | 按什么顺序向学生讲解和布置学习 | 标题、段落、图片、列表、提示、折叠说明；在页面内新建、编辑、发布作业和资料，或关联已有作业／资料／小组 |
| 正式教学记录 | 作业、提交、反馈等事实如何保存 | 作业要求和截止时间、资料内容、小组成员、提交版本、教师反馈 |

每次开课拥有自己的课程首页。例如，同一门课在不同学期可以采用不同安排，首页引用也限制在本次开课内。

```text
某门课程的本学期开课
│
├─ 课程首页
│  ├─ 页面标题                         普通标题块，可拖动
│  ├─ 教学说明                         教师在页面内编写
│  ├─ 资料引用 ────────────────────→ 某份正式资料
│  ├─ 操作步骤                         列表或其他内容块
│  └─ 作业引用 ────────────────────→ 某份正式作业
│                                      └─ 学生提交与教师反馈
│
├─ 作业与反馈                          布置作业、查看提交与反馈、维护已有作业
├─ 课程资料                            添加、检索和维护资料
├─ 小组                                进入小组页面
└─ 教学团队与课程管理
```

因此，导航层级、内容块嵌套、记录关联是三种不同的关系。在正文里嵌套一组步骤，只改变内容结构；新建或关联作业后，页面块都指向一份正式作业。教师无需先到另一页创建，再回首页寻找刚创建的内容。

## 2 一页由可以独立操作的块组成

最小编辑单位是“块”。一个标题、一段文字、一张图片和一条作业引用都可以分别移动、复制或移除。教师可以在任意两个块之间继续写说明。

| 块的种类 | 用途 | 内容来自哪里 |
| --- | --- | --- |
| 标题与段落 | 组织章节、说明目标和要求 | 当前页面 |
| 有序／无序列表、勾选清单、引用 | 编写步骤、检查项或引用文字 | 当前页面 |
| 提示与折叠说明 | 强调注意事项，收起补充材料 | 当前页面 |
| 图片 | 展示流程、示例或现场照片 | 图片地址与页面内说明 |
| 单条记录引用 | 放入一项作业、一份资料或一个小组的入口 | 页面内新建的作业／资料，或已有教学记录 |
| 记录合集 | 集中展示多项同类记录 | 教师选中的已有教学记录 |

普通勾选清单只是页面内容。勾选“完成访谈准备”不会把正式作业标为已提交，也不会生成学生成绩。

### 页面标题也属于内容块

页面标题现在是一个普通一级标题块，使用与正文相同的六点拖柄。它可以移到正文之后，也可以进入嵌套结构；预览和阅读按照保存的位置显示。

系统通过稳定的块标识识别页面标题，而不是把“第一个块”固定当作标题。移动不会改变它的身份；删除或转换为其他类型后，不会再次自动插回顶部。数据库还保留简短标题作为页面元数据，保存时从指定标题块同步；缺少有效标题文字时使用原有标题或“无标题”作为备用名称。

## 3 卡片关联什么以及如何使用

例如，教师在课程首页或「作业与反馈」点「布置作业」，填写“原型测试记录”的要求和截止时间，在要求中引用本期已发布的观察指引，再发布作业。正式作业立即保存，客户端将新引用插入当前未保存的页面编辑。此时学生可按记录权限从列表或原链接访问作业；页面的新入口和文字还需要明确发布。已有作业可以直接关联，无需重新创建。

**原作业负责要求、截止时间和提交；首页引用负责出现在哪里、以链接还是卡片展示。** 卡片名称和状态从原记录及当前访问者身份中取得，重新加载页面时反映最新数据。

这里有两个不同的标识：

- **块标识**：识别首页中的这一个位置，用于移动、复制和编辑。
- **记录标识**：识别它指向的原作业、资料或小组。

复制一个引用块，会得到新的块标识，但仍指向同一份原记录。因此，同一作业可以在两个教学段落中出现，而学生仍进入同一个作业页面。

| 教师的操作 | 实际效果 |
| --- | --- |
| 拖动作业卡片 | 改变它在首页的位置 |
| 切换链接／卡片 | 改变首页展示方式 |
| 更换关联对象 | 让当前位置指向另一份已有记录 |
| 复制引用块 | 增加一个通往同一记录的入口 |
| 移除引用块 | 移除首页入口；原记录、提交和反馈保留 |
| 在引用上选择“编辑” | 独立保存正式作业及状态，所有引用仍指向同一记录；不保存页面文字 |
| 在辅助列表中维护已有记录 | 修改同一份正式记录，检查该记录自己的修订号，不改变首页修订号 |

引用标题直接打开原作业、资料或小组，教师和管理员可以使用作业、资料引用旁的“编辑”修改内容及发布状态。引用不再每条重复附带操作说明和打开链接；引用设置中保留当前关联对象及打开入口。学生阅读时，通过引用进入详情页查看要求、提交或查看反馈。详情页给提交和反馈保留稳定位置，首页改排版或移除入口不会改变历史归属。

同一引用可以显示为简洁链接或带边框的卡片。二者的记录身份、权限和状态一致，区别只在呈现方式；可在引用设置中切换。

### 单条引用与合集如何选择

需要在两项作业之间插入不同教学说明时，使用独立引用。例如“先读说明 → 作业 A → 看示例 → 作业 B”。每条引用都可以单独拖动。

需要把数份参考资料集中呈现时，使用资料合集。合集可选择多条记录、调整内部顺序，并切换列表／卡片布局；整个合集作为一个块移动。需要穿插正文时，可以把合集拆成普通标题和独立引用。

当前合集是**手动选择的同类记录集合**，新增一份作业不会自动加入已有合集；它也不包含自定义字段、公式、筛选规则或看板功能。合集标题是合集内部的设置项，只有拆成独立内容后才成为可单独拖动的标题块。

## 4 用一次原型测试课说明页面编排

以下是编排示例，不代表系统已经创建了这些正式记录。

| 页面顺序 | 内容 | 对应块 |
| --- | --- | --- |
| 1 | 原型测试流程演示 | 页面标题 |
| 2 | 说明本次目标：通过观察发现原型的使用问题 | 段落 |
| 3 | 展示测试流程或原型图片 | 图片 |
| 4 | 阅读访谈与观察指引 | 新建或关联的资料引用 |
| 5 | 按顺序完成准备、观察、记录和讨论 | 有序列表 |
| 6 | 提醒不要替测试者解释如何操作 | 提示块 |
| 7 | 提交原型测试记录 | 新建或关联的作业引用 |
| 8 | 补充常见问题 | 折叠说明 |

教师进入首页编辑器编写教学说明，通过「插入」菜单中的「添加资料」或「布置作业」填写内容，并选择该记录保存为草稿还是发布。确认只保存正式记录，新引用进入当前未保存的页面编辑。若内容已经存在，从同一菜单选择“关联已有作业／资料”。随后保存页面草稿以便教学团队继续编辑，或发布页面更新学生看到的安排。布局模式中的左侧「＋」和 `/` 也可插入内容与新建记录。

学生按页面顺序阅读，打开资料，然后从作业入口进入正式提交页面。若教师把资料附在作业要求中，学生也可从要求直接打开。教师从「作业与反馈」进入同一份作业查看提交、给出反馈。

## 5 编辑过程如何组织

阅读课程首页时，有权管理作业的教师和管理员可以直接点「布置作业」，也可以进入页面编辑器编写教学安排。编辑界面使用单列画布，顶部以一个“插入”菜单集中内容操作，并保留取消、学生预览、保存草稿、发布页面以及保存状态。范围操作靠近当前选区；页面不常驻编辑指南、位置说明和长段保存解释。

| 操作入口 | 行为 |
| --- | --- |
| 直接输入 | 编写正文 |
| 顶部“插入”、左侧「＋」或 `/` | 新建作业／资料、关联已有记录，或插入基础内容块；打开「＋」菜单不会先插入空段落 |
| 转换为 → 关联到作业／资料／小组 | 选择已有记录作为当前入口；保留原有文字和子内容 |
| 桌面鼠标从正文旁留白或行尾空白拖框 | 实时显示矩形与块高亮，选中连续顶层整块；靠近视口上下边缘自动滚动，Escape 可取消 |
| 松手后拖动已选正文 | 整体移动框选范围，包含选中父块的子内容 |
| 拖动左侧六点 | 移动当前块或所选整块范围；内容预览跟随指针，蓝色落点线表示放置位置 |
| 六点菜单 → 选择多块 | 以当前顶层块为起点，再点终点，选择两者之间连续的顶层块；选区旁提供“拖动 N 块”和取消 |
| 点击左侧六点 | 打开复制、上下移动、插入正文、删除等块操作 |
| 引用旁的“编辑”及设置 | 编辑作业／资料内容与发布状态，或更换关联对象、切换显示方式 |
| 学生预览 | 预览当前编辑在发布可见性规则下的效果，不保存，不模拟某个真实学生 |
| 保存草稿或 Cmd／Ctrl + S | 保存教学团队共享的页面草稿，学生继续读已发布页面 |
| 发布页面 | 发布当前编辑内容并更新引用索引，不改变正式记录的发布状态 |

正文、标题、列表、清单和引用文字等基础块可以转换类型，也可以通过“转换为”关联已有作业、资料或小组。将有文字的块关联到记录时，原文字保留为引用上方的正文，子内容继续保留；取消选择不改变原块。教学记录引用、图片、提示和折叠说明不提供会丢失其专有属性的通用文字类型转换。

桌面鼠标从正文旁留白或行尾空白按住拖动，即可直接框选。矩形随指针移动，块高亮实时反映选择结果；靠近视口上下边缘时自动滚动。松手后选区继续保留，再按住已选正文或其中的六点，可以把这些块整体拖动。Escape 取消框选或当前选区。

框选针对连续顶层整块：选中父块时包含其全部子内容，首末命中之间的块一同选中。页面用范围边框和根块数量说明将移动的内容，子内容不重复计数。拖动预览跟随指针，包含内容与块数量，蓝线显示落点。当前仍不支持不连续多选。

六点菜单“选择多块”的起终点路径继续保留，选择完成后在附近显示紧凑的“拖动 N 块”和取消；触屏仍使用点按定位与菜单操作。正常文字涂选不受影响，也可以跨段选择文字后拖动选区内的六点，此时按编辑器规则扩展为同层完整块，不会只剪出被涂选的几个字。

目前采用显式保存。未保存编辑保留在当前会话中，保存后的页面草稿则由教学团队共享。取消时可放弃本次未保存的页面修改或继续编辑，刷新或离开有未保存提醒；已保存的记录和共享草稿不会因此撤销。

学生预览隐藏草稿作业和未发布资料，去掉教师统计、助教负责范围、个人提交与反馈进度；小组按实际学生的组籍决定，预览用归属提示占位。它展示发布可见性下的布局，不声称准确模拟某个学生的任务状态。

记录表单的确认按钮说明当前记录的动作，例如保存草稿、发布、结束或取消作业、撤回资料。在作业表单中选择配套文件并点「发布资料并引用」，会立即将文件发布到「课程资料」。作业单独保存，即使放弃本次作业编辑，已发布文件仍可从资料目录找到。正式记录新建成功后也可从对应目录找回。

页面草稿和已发布文档分开保存。学生读取接口不返回页面草稿；发布页面也不会自动发布其中的草稿作业或资料。已发布记录的更新立即按其权限生效，页面草稿不会把该记录冻结为旧内容。

## 6 同一个页面如何适配不同角色

页面布局由教学团队编排，记录信息按访问者的权限读取。学生、助教与教师可以看到相同的教学段落，但作业卡片上的状态、统计和操作入口可能不同。

| 角色 | 首页编排 | 记录呈现原则 |
| --- | --- | --- |
| 本期有效教师 | 可编辑未归档课程，并在首页管理作业与资料 | 查看教学管理所需的全班信息 |
| 本期有效助教 | 可编辑未归档课程，关联有权读取的已有记录 | 待反馈信息按负责范围呈现；编排首页不会获得发布作业／资料或读取隐藏资料的权限 |
| 学生 | 只读 | 查看有权访问的作业与资料，以及本人相关提交、反馈和当前所属小组 |
| 管理员 | 可编辑未归档课程 | 使用管理权限；首页编辑权不自动赋予教师反馈署名资格 |
| 归档课程的访问者 | 只读 | 在原有权限范围内阅读历史内容 |

权限过滤在服务端完成。对于助教不能读取的资料引用，编辑器使用不显示真实记录信息的保留提示；保存时由服务端保留受保护的关联，避免助教编辑其他段落时意外删掉隐藏资料。

作业卡片分别显示生命周期和个人进度／负责范围统计：草稿学生不可见；已发布作业在课程进行中且未截止时接收提交；截止或结束后仍可读要求与已有反馈。取消作业显示原因，不再要求完成，不再催交，但旧要求、提交和反馈保留；恢复需明确重新发布。资料撤回意味着学生和助教不能再读；课程归档则让整次开课进入历史只读。移除首页引用只改变当前编排，发布后移除学生入口，不撤回记录。具体规则见[课程内容的创建发布与历史保留](course-content-lifecycle.md)。

首页中的“其他待办与反馈／待反馈”由系统根据教学状态生成，独立于正文编辑器。系统会排除已发布首页中列出的作业及所有已取消作业；草稿引用不改变学生待办。删除正文不删除待办计算规则。管理员、筹备期和归档课程不生成这一区域的待办。

## 7 数据如何保存与重新显示

当前实现使用 BlockNote 负责块编辑交互，项目自己的文档格式负责存储，普通 React 组件负责阅读和预览。阅读页面无需启动富文本编辑器。

一个文档包含格式版本、内容块数组和页面标题块标识。每个块包含稳定标识、类型、属性、行内文字和可选子块。例如：

```text
课程页面文档
├─ 格式版本
├─ 页面标题块标识
└─ 内容块数组
   ├─ 标题块：标识、级别、文字
   ├─ 段落块：标识、文字、文字格式
   └─ 作业引用块：块标识、记录类型、原作业标识、显示方式
```

本次开课的 `CourseFocus.document` 保存已发布文档，`draftDocument`、`draftTitle` 和 `draftSavedAt` 保存教学团队共享草稿，`publishedAt` 记录页面发布时间。作业和资料关联表只索引已发布页面；提交、反馈和小组成员仍在各自的数据表中。

**读取时**，服务端检查访问者和课程权限，筛选可见记录，再解析引用。学生只获得已发布文档；教学团队还可读取共享草稿，打开编辑时优先继续草稿。学生预览使用面向发布可见性的投影视图，不复用教师统计当作学生进度。

**保存页面时**，客户端提交当前编辑内容和页面修订号。服务端检查权限、课程状态、结构和同期开课引用。保存草稿只更新共享草稿；发布则写已发布文档、同步标题与索引并清空草稿。两种操作都检查并递增页面修订号，发布不会隐式取一份过时的服务器草稿。

**保存作业或资料时**，只写这份记录并检查它自己的修订号，不保存页面。新建成功后由客户端在当前未保存编辑中插入引用。相同创建请求使用稳定标识重试返回同一记录；以同一标识提交不同内容则拒绝。页面保存失败或被放弃后，已创建的记录仍可找回并重新关联。

页面修订号与记录修订号互不替代：更新记录不递增页面版本，保存或发布页面不改写记录版本。旧版本保存被拒绝，避免静默覆盖；目前没有自动合并、多人光标或实时协作。系统保留一份共享页面草稿和一份已发布文档，不是完整的页面版本历史。

作业要求另有不可改写的修订历史。每次新提交绑定当时要求修订，包含标题、说明、方式、截止时间、满分、状态和取消原因。以后修改要求不回写旧提交；详情按需展开“提交时的作业要求”和“修改记录”。旧提交若未记录快照则明确未知，后来创建的基线不能充当当时要求。当前没有正式记录、提交和反馈的物理删除入口。

旧页面在读取和打开编辑器时按需转换，首次显式保存后才写入新结构，不会批量改写已有课程。结构校验目前限制为 250 KB、250 个普通内容块、最多 6 层嵌套和 60000 个正文字符；迁入的页面标题不占用原有 250 个内容块名额。

## 8 当前边界与后续扩展方向

| 方面 | 当前已实现 | 后续扩展时需要补齐 |
| --- | --- | --- |
| 页面范围 | 课程首页块编辑 | 作业正文、小组记录分别接入编辑权限和保存流程 |
| 页面组织 | 固定课程导航，正文可嵌套 | 任意子页面树、页面移动和继承权限 |
| 记录展示 | 单条引用、手选同类记录合集 | 动态筛选、排序规则、自定义字段和其他视图 |
| 内容发布 | 记录独立保存；页面共享草稿与显式发布分离；学生预览使用发布可见性投影 | 完整页面版本历史；筹备期学生可见性统一 |
| 作业历史 | 取消免交保历史；要求修订不可改写；新提交绑定当时要求，旧未知快照不回填 | 附件历史与更多要求变更通知 |
| 范围拖动 | 桌面留白直接框选、已选正文整体拖动、边缘自动滚动；连续顶层起终点选择、原生跨段选区拖动及跟随预览 | 不连续多选及更多触屏批量操作 |
| 图片 | 已有图片地址及说明 | 本地上传、文件存储和私有资源鉴权 |
| 协作 | 共享页面草稿；页面和记录各自进行修订号冲突检查；新建请求幂等 | 自动保存、冲突合并和实时协作 |
| 布局 | 单列内容、卡片或列表呈现 | 多栏编排及移动端重排规则 |

课程筹备状态仍允许有效学生读取已发布页面及记录，只是不接受作业提交。助教编排与发布页面不授予正式作业、资料管理权。小组工作记录仍保存即生效，阅读依当前组籍；历史提交按参与快照保留。所有引用限定在本次开课，跨期模板复制尚未实现，不能把旧学生提交或反馈带入新学期。

若继续扩展，优先保持现有的数据关系：内容块控制教学表达，正式记录控制教学流程。把块编辑器用于作业正文或小组记录时，应复用编辑和渲染能力，同时分别接入该场景的权限、提交封存与历史记录规则。
