# 写作与编排课程页面

## 连续写作与预览

课程首页点「编辑课程首页」，课次点「编辑课次」。标题单独填写，正文是一块连续的 Markdown 输入区，文字、课次、作业与资料引用可以一起选择、剪切、复制和移动。空行分段；正文工具条提供标题、粗体、斜体与列表，「更多格式」包含有序列表、任务列表、引用、代码、表格和分割线。列表中 Enter 续行，空项 Enter 退出；Tab／Shift+Tab 调整缩进，Esc 后 Tab 离开正文。撤销与重做覆盖文字修改、插入、格式和粘贴，也可使用 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z。

「学生预览」显示排版和发布可见范围。链接在新标签按当前教学身份打开原件；点「继续编辑」回到原选区，撤销历史仍在。预览不模拟某位学生的提交状态；学生真正打开时显示本人或当前组的状态。保存草稿只保存教学团队共享的正文；发布课程首页或课次后，学生才读到新正文。Cmd/Ctrl+S 保存草稿。没有自动保存，退出或离开前仍检查未保存修改。

## 插入课次、作业和资料

点正文旁「插入」，按作业、课次和资料选择内容。作业列出实际截止，可搜索标题，并在新标签打开原作业核对；资料可先点「预览」查看内容。引用自动带上原件关系，不需手写网址或编号；编辑区的「正文中的引用」随引用增删和撤销同步。课次仅可从课程首页引用；草稿在选择结果中标明，未发布时学生看不到。教师和管理员还可在这里新建作业或资料；成功保存后，引用加入当前正文，页面仍需单独保存或发布。

插入位置在光标所在完整段落、列表、表格或代码块之后，避免切断已有格式。引用落为一行，可以和说明一起剪切粘贴；放进句子或列表时，作业显示标题链接和简短截止，单独成段时为简洁事项行。

| 引用 | 阅读时显示 | 点击结果 |
| --- | --- | --- |
| 课次 | 原课次标题 | 进入该课内容 |
| 作业 | 原作业标题、提交方式、实际截止、必要状态 | 进入要求页，再从原作业进入提交情况或提交成果 |
| 资料 | 原资料标题、文件格式、预览、打开或下载 | 预览可查看 PDF、常见图片与纯文本；其他格式下载，外链打开原站 |

标题及截止等信息读取原件，原件更新后重新打开正文即可看到；删除引用只从这篇正文移除入口，不删除作业、资料或既有提交。未发布和已撤回内容继续遵守各自权限。作业取消时显示免交，不再用截止和待交状态催交。

正文上方的「插入图片」使用网址，可填说明。小组从课程导航进入，不再作为插入菜单中的内容项；正文里已有的小组链接继续保留。选中文字可点「插入链接」或按 Cmd/Ctrl+K，普通网址按普通链接保存。Cmd/Ctrl+B 和 I 切换粗体、斜体。需要新课时，从导航「课次」中的「新建课次」创建草稿，再在该课编辑和发布。

## 保存、发布与旧内容

正文和引用已发布内容时，正常发布一次完成。引用到作业、资料草稿等需要核对的状态时，页面显示发布范围。教师可明确勾选一并发布的作业、资料及配套文件；未选项目继续是草稿。课次草稿仍在原课次发布。预览按当前核对与勾选结果展示，不会因插入引用就改变原件状态。

旧折叠、特殊样式、复杂嵌套等不能忠实转换成普通 Markdown 的内容，保留为整行「保留原内容块」标记。整行移动会移动原块；普通正文修改不丢原样式或子内容。需要修改这些旧内容时，从「更多页面操作」进入「调整布局」，然后返回写作。无法安全拼接的旧 Markdown（例如未闭合代码围栏或局部链接定义）也保留其原解析边界。受限资料使用不含标题或真实记录 ID 的保留标记，服务端保持原引用与语境，编排权不会扩大资料读取权。

教师在作业或资料原页修改正式内容。首页的「保存草稿」不撤销已保存的正式记录；放弃页面编辑也不会删除已经新建的作业或资料。撤回首页正文后，学生仍可从课程导航打开已发布的课次、作业和资料。

## 调整旧布局时的 BlockNote 模式

使用 `@blocknote/core`、`@blocknote/react`、`@blocknote/mantine` 0.56.0，许可证为 MPL-2.0，未引入 XL 扩展或商业 Notion 模板。保留依赖包许可证。课程专用组件由项目自行实现。

编辑器通过客户端动态导入，在打开编辑界面时加载；日常阅读使用普通 React 渲染，不需要运行富文本编辑器。原生正文采用白色背景、深蓝操作色，与已有教学页面一致。

布局模式使用无边框的单列画布，以一个“插入”菜单提供新建作业／资料、关联已有记录和基础内容块；左侧「＋」使用同一菜单，打开菜单不会预先插入空段落，`/` 也可新建作业和资料。页面不常驻操作指南、位置说明或保存解释行，提示在相关操作中出现。

页面标题也是普通一级标题块，可使用六点拖柄移动到正文任意位置；预览、保存和再次打开保留位置，不会在顶部重复插入。删除或转换标题后也不会自动补回。标题直接输入，回车进入正文。左侧操作区属于编辑器的悬停范围，带边框的加号与六点拖柄按实际首行对齐；六点支持点击打开菜单与拖动排序。标题、正文和每条教学引用分别作为独立块，可以在标题与引用之间继续写作。触屏可点按定位，键盘可用 Alt+Shift+B 打开当前块菜单。

拖柄菜单提供选择多块、创建副本、上移、下移、上下插入正文及删除；正文、三级标题、列表、清单和引用可相互转换，保留原块 ID、富文本及子块。“转换为”也包含“关联到作业／资料／小组”：先选择已有记录，确认后建立引用；原有文字保留为引用上方的正文，子内容继续保留，取消不改变内容。自定义教学记录、图片、提示框和折叠说明不提供会丢失专有属性的通用文字类型转换。

桌面鼠标可以从正文旁的留白或行尾空白按住拖动，直接框选内容。矩形随指针移动，被框中的块实时高亮；指针靠近视口上下边缘时自动滚动。松手后保留整块选区，可以直接拖动已选正文或其中的六点，把内容整体移到新位置。Escape 取消框选或当前选区。

框选得到连续的顶层整块范围，选中父块时包含其全部子内容。范围边框与块数量说明实际移动范围；拖动预览包含内容与数量并跟随指针，蓝色落点线标出位置。数量按实际移动的根块计算，子内容不重复计数。当前仍不支持不连续多选。

六点菜单中的“选择多块”继续提供起终点选择，完成后在选区旁显示“拖动 N 块”和取消；触屏仍使用点按定位和菜单路径。正常文字涂选保持原有行为，也可以跨段选文字后拖动选区内的六点，此时按编辑器规则扩展为同层完整块，不会只剪出段落里被涂选的几个字。

关联记录时可搜索并用键盘选择，首次插入后回到正文继续写作。引用标题直接打开原记录，教师和管理员可在引用旁点击“编辑”，`•••` 提供链接／卡片切换及更换关联。引用本身不重复附加操作说明和打开链接；设置菜单保留当前关联对象与打开入口。显式插入的合集支持多选与排序，也可拆为普通标题和独立引用，保留原显示方式。提示框通过图标选择类型；折叠说明可直接展开或收起正文与子块。浮层支持 Escape、点击外部及 Tab 离开关闭，适应窄屏。

顶部保留保存状态、取消、学生预览、保存草稿和发布页面。Cmd/Ctrl+S 保存页面草稿，不发布。预览保留编辑器状态并关闭配置浮层；保存时禁用编辑控件。仍采用显式保存，没有自动保存或实时协作。

作业／资料表单只保存当前正式记录。新建成功后，编辑器将引用插入当前未保存内容；修改已有记录立即作用于该记录的所有引用。它们不保存整页、不递增页面修订号，也不会把当前文字变成已发布内容。页面草稿和已发布页面分别保存；记录表单中的“草稿／发布”控制记录本身，与页面的“保存草稿／发布页面”相互独立。

学生预览对当前编辑应用发布可见性规则：隐藏草稿作业和未发布资料，不携带教师统计、助教负责范围或个人提交进度。小组按实际学生的组籍显示，预览采用归属占位，不模拟某个真实学生。预览不是保存；没有在发布核对中勾选的正式记录仍保持草稿。

发布前重新读取有权查看的正式记录状态，按记录去重汇总草稿、已发布、已结束、已取消和已撤回情况。存在学生不可见、状态未知或受保护关联时，出现行内核对；再次确认会重读状态，关联对象或状态有变化时重新核对。正常发布仍一次点击。核对保留当前编辑、撤销记录和未保存正文；摘要不输出受保护记录标题、正文，也不推测其数量。正式记录表单在保存前说明立即生效的影响，与页面发布分开。

参考：[Next.js 接入](https://www.blocknotejs.org/docs/getting-started/nextjs)、[自定义块](https://www.blocknotejs.org/docs/features/custom-schemas/custom-blocks)、[BlockNote 源码与许可](https://github.com/TypeCellOS/BlockNote)。

## 文档与业务记录

`CourseFocus.document` 保存已发布的 `version: 1` JSON 文档，`draftDocument` 保存教学团队共享草稿；每个块具有稳定 ID、类型、受限属性、正文和子块。`courseRecord` 只存单条记录 ID，`courseData` 保存显式组合视图。连续写作在 `markdown` 中保存 `[标题](course:类型/ID)`；链接的文字供编辑辨认，阅读时的标题、截止和状态始终取自可读原件。服务端从实际 Markdown 链接收集引用，代码示例不算教学关联。移动、复制或移除页面引用不会修改正式作业和提交记录，复制块会生成新的块 ID。

主页负责当前教学安排，正式记录的状态负责可见性和是否接收提交。移除引用不会撤回已发布内容，原链接与辅助列表仍能通往同一记录。作业截止或结束后保留要求、提交和已有反馈；取消作业不再要求完成，从应交与常规待办移除，保留原因和历史，允许明确恢复发布；资料撤回后学生与助教不可读；课程归档后整期只读。当前没有正式记录的物理删除入口，详见[课程内容生命周期](course-content-lifecycle.md)。

读取时先按当前身份获取可见教学记录，再把引用解析成视图。学生看到本人的提交状态；教学人员从原作业的提交情况进入负责范围或全班统计。引用行显示必要的草稿、已结束、已取消等状态；取消后不再显示催交，历史反馈仍可打开。小组视图对学生只展示当前所属小组。普通勾选清单是教学正文的一部分，不能改变正式作业状态。

`CourseFocusAssignment` 与 `CourseFocusResource` 是已发布页面的引用索引，仅在发布页面的同一事务中更新；保存共享草稿不改索引。系统待办按已发布安排排除已列出的作业，取消作业不进入常规待办。正文与待办计算独立，删除全部内容块也不删除待办规则。

作业有独立的不可改写要求修订，包含标题、要求、提交方式、截止时间、满分、状态和取消原因。新提交核对表单显示／确认的要求修订、当前归属和最新提交标识，冲突时保留草稿并要求明确核对；通过后绑定要求修订，以后编辑不改写既有绑定。最新提交的比较标识不暴露无权读取的历史内容。详情折叠查看“提交时的作业要求”和“修改记录”。旧提交未留快照时明确标为未知，不用当前要求或后来创建的历史基线回填。

每个提交版本另有待评阅、本轮评阅完成或历史状态未确认，状态修改检查修订并保留历史。评论不会自动完成评阅，没有评论也可以完成；新版本重新待评阅，不继承旧版状态。完成评阅不等于学生通过或被要求重交，这些教学结论仍待建设。

## 保存与权限

- 本期有效教师、助教和管理员可编排课程首页；学生只读，归档课程所有身份只读。
- 正式作业与资料的创建、编辑和发布仍限教师及管理员；助教获得页面编排权，不会因此获得业务管理权。小组仍在课程管理中创建，工作记录保存后按当前权限立即生效。
- 服务端验证标题、文档结构、URL、大小、层数、块数量与跨学期引用。禁止任意 HTML、脚本和不支持的块类型。
- 文档最多 250 KB、250 个块、6 层嵌套，正文合计最多 60000 字。
- 助教不能因编辑页面获得草稿或下架资料。隐藏引用用不含真实记录信息的保留标记表示；服务端合并保存，避免无权读取的关联被误删。
- 页面保存草稿和发布共用 `CourseFocus.revision` 的乐观并发检查。草稿只向教学团队返回，发布写入当前提交的文档并清空草稿；首次保存草稿不产生学生可见的正文。
- 作业和资料分别携带自己的 `expectedRevision` 保存。记录版本冲突不覆盖他人修改；更新记录不递增页面版本，页面发布也不修改记录版本。
- `course-page-records.ts` 独立保存正式记录，客户端在新建成功后插入本地引用。保存记录不提交页面；页面冲突或放弃页面编辑不会回滚已经保存的记录。未发布到主页的记录可从列表找回。
- 新建请求携带稳定请求标识，相同创建内容重试返回同一记录；标识被不同内容复用则拒绝。取消新建作业会放弃未保存的作业，表单中已单独发布的配套文件仍在「课程资料」中。
- 「作业」的「布置作业」指向课程首页的 `?create=assignment`，到达即打开新建作业表单。「课程资料」可就地添加资料。两处目录都可维护已有记录，保存时检查该记录的修订号。
- 编辑采用显式保存。未保存内容在当前编辑会话中；保存后的页面草稿由教学团队共享，不是个人草稿。取消、刷新或离开时提示未保存修改，放弃页面编辑不撤销已保存的记录或共享草稿。
- 筹备中课程仍允许有效学生阅读已发布主页及已发布内容，只禁止提交；这不等于教师私有准备区。当前没有完整课程页面版本历史或跨学期模板复用。小组文字记录另有修订冲突检查及不可改写历史，载入旧版后保存会形成新编辑，不回写旧历史；它尚未复用本页面的块编辑器。

## 旧内容兼容

块文档及后续草稿发布字段通过增量迁移加入，不重置已有页面。旧正文按段落转换，安全的旧关联视图转换为普通标题与独立引用；读取时兼容，首次显式保存才写入转换结果。含隐藏记录、小组、空内容或拆分会超限的旧视图保留整体，避免泄漏配置标题或截断内容。转换使用稳定块 ID，不拆开用户主动输入的软换行。旧正文和关联表继续保留，旧表单服务不得覆盖已经保存为块文档或共享草稿的页面。旧提交未保存的要求快照不由迁移推测补齐。

## 验证

编辑器、服务与数据库分别验证。现有验证范围包括块转换和范围选区、角色与跨期权限、隐藏记录保留、归档、并发保存和旧内容转换。生命周期验证还需覆盖共享草稿不向学生泄漏、发布更新索引、记录与页面版本互不干扰、创建幂等、取消与恢复、不可改写的要求修订、新提交绑定及旧提交快照为空。

此前浏览器验收已核对三块整体拖动、跨段文字选区拖动、范围框与跟随预览、放下顺序和撤销；转换已有作业保留原文，取消不改文档。入口精简后也检查了顶栏“插入”、左侧加号、斜杠新建、邻近范围拖柄及 390 像素窄屏布局，测试编辑未保存到课程。这些结果只说明对应编辑交互，不代替新的草稿、发布、独立记录保存和学生预览验收。

运行 `npm test`、`npm run typecheck` 和 `npm run build` 检查当前提交；数据库测试使用隔离临时库。部署前应应用对应迁移，不从本文推断某个运行实例已经升级。

### 2026-11-01 桌面 Safari 核心流程补验
