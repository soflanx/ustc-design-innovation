# 设计方向

## 2026-11-10 插入内容与资料预览

正文的统一入口称为「插入」，面板按作业、课次、资料选择内容。移除「小组工作记录」快捷插入；小组由课程导航进入，已有正文中的旧链接继续作为普通链接保留。编辑时按实际引用展示作业、课次和资料，作业显示截止，资料提供预览。

资料在选择结果与正文引用旁按需打开预览：PDF、常见位图和纯文本直接查看，其他文件保留下载，外链打开原站。预览关闭后继续原处写作；预览读取复用资料原有权限，不改变发布范围。本节替代下方「插入作业」作为总入口以及小组工作菜单的约定。

## 2026-11-10 写作时可见的作业与 Markdown 操作

连续正文旁直接提供「插入作业」，默认列出作业标题、实际截止和打开原件的入口；课次、资料和小组工作在同一面板切换。编辑区只列当前正文实际引用且有权读取的作业，重复引用合并，删除和撤销同步。取消作业显示免交，没有截止则明确显示未设截止。句中和列表内的作业引用也带简短截止，信息始终取自原作业。

常用格式留在正文工具条，更多格式包含有序与任务列表、引用、代码、表格及分割线；普通链接可对选中文字插入。列表回车续写，空项退出，Tab 与 Shift+Tab 调整缩进，Esc 后 Tab 离开正文。格式、链接和输入共用撤销历史；会破坏受管引用或旧内容标记的辅助命令保留原稿。

编辑中的作业入口和学生预览链接在新标签查看原件，保留原编辑稿、选区与历史。预览说明仍以当前教学身份打开原件，不冒充实际学生。发布重新核对时使用最新的截止、提交方式和状态，已取消作业不显示旧截止。本节更新下方顶部「插入引用」及句内只显示标题的旧约定。

## 2026-11-10 课堂记事与个人回顾的归属

请假、未到和课堂发言从具体课次的「课堂记录」发起。用「记学生情况」从本期名单多选学生，一次保存同一种情况；请假与未到可只选人，发言填写正文。只为选中的学生产生本课记录，不从未勾选推断出勤。请假表示收到请假消息，不新增审批或确认流程。原「记一笔」继续承载整堂课、单人或小组的自由记录。

学生和小组页只新写普通的「个人备注／小组备注」。表单只有正文，作者和保存时间自动记录，不显示课堂类型、来源和日期；来路课次仅用于返回，不自动变成备注归属。旧入口留下的私稿单独恢复供阅读、复制或清除，不把其中隐藏的分类和情境静默写进新备注。

回顾页按已有内容显示个人／小组备注、按课次组织的课堂记录、作业与评语。作业同一份提交默认只占一项，显示该生实际参与的最新版本及评语；原提交人、版本、完整评语和旧版本可展开。没有课次而明确关联作品的内部备注放在对应提交详情中，保留具体版本；同时关联课堂和作品的备注按课次读，并可到原作品。旧发出留言单独折叠，标明当时对象，不混作版本评语。记录正文优先，保存时间、更正及撤回控制在详情内。

本节替代旧人组页的类型选择和所有记录按时间平铺的呈现。已有数据、版本参与快照与读权限不改；未关联课次的旧课堂记录保留未知。

## 2026-11-10 连续 Markdown 写作与原件引用

首页和课次使用一个连续正文输入框。文字与引用在同一选区内复制、剪切、移动，文字修改、插入和格式操作使用同一套撤销／重做。少量格式按钮放在正文上方，顶部只保留「插入引用」、预览、保存和发布等页面操作。预览期间保留输入框与历史，返回后恢复选区和焦点。

「插入引用」统一搜索有权读取的课次、作业和资料，按原件关系生成链接；插入时落在完整 Markdown 结构之后。句中的引用只呈现原件标题，独占段落显示紧凑事项行。作业标题对所有身份先到要求，提交情况从原作业进入；行内不堆统计，独立事项按需显示提交方式、真实截止和学生自身状态。资料标明格式及打开／下载，仍从受保护的原文件入口交付。原件改名或更新截止后，阅读引用同步读取最新值。

发布核对和读权限同时识别 Markdown 内的教学引用。正文草稿不对学生提前显示，未选草稿不因引用而自动发布，助教不能借编辑正文读取受限资料。旧折叠、复杂样式及有独立解析边界的 Markdown 保留原块；编辑中用可移动保留标记表示，正常保存后才写回。对含受限引用的原句保留整个原段落及语境，可编辑其前后段落。旧页接近字数上限时，未改动的独占引用沿用原块，避免仅因写法转换就超过保存限制。

本节替代下文默认分段文本框、六点移动引用及摘要展开统计的写作约定。旧布局模式继续用于特殊内容编排，具体操作见[课程页面使用说明](docs/course-page-editor.md)，实际验证范围见[体验走查](docs/experience-review.md)。

## 2026-11-09 以课次、学生与作品组织连续工作

用户认为五项功能实现后的页面仍然难理解：主页固定回顾／准备、编辑入口重复，课堂记录在课与人组之间跳转，学生页有空栏目和并不需要的指导流程。按[整站设计取舍](docs/course-workflow-redesign.md#用户截图复审后的设计取舍--2026-11-09)完成本轮重构。本节替代下文相应的固定首页、独立记录工作台与发送指导入口；历史实施记录保留。

首页用一份助教自由安排的正文和一个编辑入口；课次目录负责新建课次。同一课次内阅读教学内容或教学团队内部课堂记录，记录整堂课不必选人，关联学生或组按需填写。学生标题直接连当前组，旧组关系只有发生时才补充；正文连续阅读已有备注、作品和评语，不铺空栏目。小组以成员、自由正文和实际历史为主。评语留在原作业，统计单独进入，取消专门发／收“指导”的产品入口。

视觉层次由标题、正文、轻量来源信息和本页主要动作构成，不按数据库关系堆栏目和表单。返回保留原课次、学生与姓名筛选、统计范围，小组页只呈现最直接的一个返回入口。作品采用独立版本地址；教学端由学生旧作品切换到同组较新版本时，可以返回原学生，但新版本仍显示实际参与者，不改写个人经历。回链参数逐级核对同期开课、真实组籍与提交版本。

旧首页回顾和准备的文字、课次引用分别从已发布正文和私稿转换为普通块，正常保存后才回写，反复打开不重复插入。已有记录、旧组成果和已发内容保留原件与读者规则。旧未发留言草稿仅在原账号和情境下恢复供复制或清除，不重新出现发送流程。整课备注由同期开课的课次直接承载，不借用虚构人组；未关联课次的旧备注保持未知。

实际业务的首页编辑发布、课次内容与记录、学生与旧组／作品往返、统计评阅和归档只读已在隔离课堂用后台 Safari 复走，详见[体验走查](docs/experience-review.md)。这些操作和窄屏测量不代替真实助教无提示试用。

## 2026-11-09 助教的五项日常操作

本轮以看学生、看作业统计、看小组、更新首页、开始新课为直接任务。教学团队导航提供「学生」「小组」「课堂记录」，学生目录可按姓名查找，未分组、没有记录和归档学生也能进入。个人介绍作为普通材料，不设个人评估档案，不要求逐条关联观察、判断和指导。

学生与小组回顾先读已有内容：课堂备注按所关联课次排列，作业直接显示原版评语，指导保留原作者与当时接收对象。个人页另列当前及过去组籍；小组页保留组内工作正文。写记录和发反馈的表单按需展开。个人的随组成果依提交时的参与快照取得，不能因当前入组而把以前的小组作品算给该生。由学生的小组经历进入旧组后可直接返回该生，已有课次情境继续保留。

作业详情用「已交」「未交／逾期未交」「待评阅」「已评阅」进入同口径名单。助教默认负责范围，可切全班；个人作业另有未分组学生入口。每个对象只计算最新正式版，取消作业仅统计已有提交。更正历史保留旧版本，不参与当前重复计数。

课程首页提供「更新课堂提示」和「准备新课次」。两段提示可直接编辑、暂存或发布，单独发布只更新回顾与准备，保留已发布正文及另存的正文草稿；完整首页正文仍从「编辑课程首页」进入。新课只要求标题，正文、已有作业和资料均可选。保存后进入该课编辑器，可继续发布或从「记录与回看本次课堂」开始记事。作业与资料沿用原件，不复制任务或重置截止。

课堂记录支持切换记学生或记小组；从课次进入时自动带入课次，选对象、写正文即可保存。类型、来源与日期继续按需补充。内部备注仍只供本期教师和助教阅读，发布课次或首页提示不会将它们外发。当前回顾按本期历次课次组织，往期从各自归档课程进入。

## 2026-11-08 从正式成果到现场观察

学生围绕一份当前正式成果完成交付，可写简短说明并附主报告、统计表等多份文件。当前成果和回执先显示，更正历史按需展开。更正时可保留原文件或替换部分材料；旧材料、提交要求、当时组员与反馈始终留在原版本。附件最多 20 件，合计 10 MiB；刷新后保留文字和选件记录，文件本体需要重新选择。

截止前直接更正；截止后由教师或助教在某一份已交成果上开放明确期限，并可撤销。该动作不改变全班截止时间，也不允许未交者首次补交。换号、要求变更和新成果冲突均先保留草稿并核对，附件复选框的显示应与实际取舍一致。组员更新成果时，核对区直接列出当前成果的可读附件；仅交文件时说明未附文字，避免用空白内容让学生猜测这次变化。

取消作业会暂停更正，不自动删除已有授权或延长期限。教学团队在取消页和恢复编辑表能看到实际尚未到期的授权，并可在恢复发布前撤销；取消期间不能新增或延长。学生只看到自身成果的暂停期限。恢复时仍有效的授权继续生效，旧草稿须核对新的作业要求。作业编辑保存核对打开表单的账号，换号或退出时保留输入并拒绝写入。

教学团队从课次进入小组，先看正式成果，再从成员姓名进入学习记录。未分组学生也有入口。成员页默认展开内部观察，作者和记录时间自动保存，情境与发生日期选填；可单独记录学生，也可针对其参与过的一份成果。小组观察放在小组上下文。内部观察只供本期教师和助教阅读，另设「给学生／小组反馈」，发送前直接说明读者。学生从「指导反馈」收取这些消息，原有版本评语继续留在对应成果。

查看成果后可回到原成员或小组，并保留原课次。观察与未发送反馈的私稿在同一标签内保留，页面导航或刷新后可恢复正文、情境和日期。私稿按账号、对象、对应成果与用途区分；保存被拒绝时保留，成功后只清除对应草稿。课程归档后，有私稿的作者仍可查看和复制，但不能发送；没有私稿不显示空表单。采用浏览器会话存储，不承诺跨设备或标签关闭后的恢复，也不把私稿写入共享记录。教学团队按学生回看只列实际历史参与；新组员能读本组共享成果与全组指导，但不回填旧参与名单，个人反馈不扩散。

本轮贯通备课、正式交付与现场跟进。小组仍使用原有自由正文，带材料、发生时间与参与者的独立活动记录尚待下一轮；展示选材和班内／互联网确认、助教动作权限的进一步细化也仍待完成。

## 2026-11-08 从准备课次到学生收到内容

课程首页保留学期导览与当前说明，独立的「课次与活动」完整列出已发布课次，教学团队另见草稿。入口用「准备课次」「编辑课次」说明正在处理的内容；不能把新发布的课次藏在最早四项之后。周次与日期仍由教师按实际教学命名，本轮没有增加强制教学周字段。

教师在正文中「加入作业／资料」，可以选择已有记录，也可以新建。课次内新增记录默认先存草稿，配套文件随「保存作业草稿并加入正文」一起保存并引用，继续写课无需先把文件公开。文件先保存成功而作业被拒绝时，明确告诉教师文件已在资料草稿中；重试沿用同一记录。首页和作业目录的「布置作业」则独立打开表单，不把教师带进首页编辑，也不修改首页正文。

发布课次先核对当前引用。只有草稿、撤回或受保护内容需要行内核对，普通正文和已可读引用由一次发布操作完成。教师明确勾选的作业及资料草稿与正文在同一事务发布；未选仍为草稿，已撤回、已结束或已取消内容不会被顺带恢复。作业中的配套资料也纳入核对。学生预览按最新核对结果与勾选范围显示，其他页面改变记录后必须重新核对。

作业仍是跨课次共享的独立记录。发布时说明它也可从目录及其他已发布页面打开，避免把可见范围误解为只在当前课次。备课和学生阅读路径去掉满分输入与默认分数显示，既有数据库字段继续兼容保留。本轮先完成备课与内容交接；正式成果更正、附件交付与内部点评继续按思维课需求基线实施。


## 2026-11-02 课程子页面与连续写作

课程首页负责导览；工作坊、观察指南和作品选读可各成一页。子页只设一层，改名不影响网址。首页和子页默认显示标题栏、连续 Markdown 正文和按需出现的插入菜单。图片、作业与资料可以用左侧六点手柄在正文中拖动；单击手柄可更换、逐步移动或移除。旧页面的复杂编排仍保留在「调整布局」。具体例子和操作见 [课程页面使用说明](docs/course-page-editor.md)。



### 教学引用为什么只留一行摘要

作业标题直接通向当前身份要处理的位置：助教进入负责范围，学生进入自己的提交或反馈。下一行只显示影响当下决定的信息，例如「负责范围已交 0/1 组 · 11/15 23:59 截止」。不再为同一地址放第二个“查看”链接。需要了解完整进度或切换到全班时可以展开摘要。取消、截止和草稿状态不能藏在展开项里。

这里借用 [Notion 的拖动手柄](https://www.notion.com/help/writing-and-editing-basics#drag-and-drop)，把移动和对象菜单合并在一个入口；参考 [Confluence 的 Smart Link 视图](https://support.atlassian.com/platform-experiences/docs/smart-link-view-options/)，在正文中优先表现引用，而非展开一张详情卡。按 [W3C 的拖动替代指引](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements)，同一手柄也提供可点按的移动命令。

## 2026-10-28 登录后的教学首页

本节更新下方旧有的品牌回公开首页、顶栏统一称“全部课程”和只显示关联内容的约定。

- 明确网站首页、我的课程与课程首页三层。网站首页继续对所有人开放；登录默认进入教学空间，一门进行中课程直接进入，多门先选课程；具体作业和资料的登录回跳继续保留。

- 当前说明、本次任务与资料之后，紧凑展示未被关联到本次教学的待办与反馈。学生显示仍可提交的未交任务、未分组提示和已有反馈，教师显示全班待反馈，助教只显示负责范围的待反馈。已有反馈不声明未读，草稿不当作待反馈；默认三项，其余按需展开。
- 同一作业不在本次任务和补充事项中重复。无补充事项时不留空面板；筹备期、归档期和管理员不展示教学待办。手机页头保留课程定位、课程列表、公开门户与账户入口，并维持可点击尺寸。

具体页面原则：

- 公开首页的首要任务是解释课程与展示项目。照片、视频与大标题应有明确内容归属；真实的工作场景、访谈、原型和项目过程优先于通用校园形象素材。
- 登录后让用户尽快进入当前课程。仅有一个当前课程时可直接进入课程工作页；多个课程时先选择课程。身份跟随课程和学期，不让用户在每次访问时手动选择“我是教师/学生”。
- 学生、助教、教师共享同一个课程结构，以首页信息优先级和操作权限体现差异。助教默认聚焦负责小组，同时保留当前规则允许的全期浏览能力。
